# Simple Python Calculator

A beginner-friendly command-line calculator for addition, subtraction, multiplication, and division.

## Requirements

- Python 3

## Run

```bash
python calculator.py
```

Enter two numbers and choose `+`, `-`, `*`, or `/`. The program reports invalid input and prevents division by zero.

## Learning notes

This small project demonstrates functions, user input, conditionals, error handling, and formatted output. It is a simple practice project and can be extended with more operations or a graphical interface.
